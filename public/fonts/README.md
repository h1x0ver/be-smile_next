The upstream Manrope 4.505 variable font contains lowercase ə (U+0259), but no
capital Ə (U+018F). The BeSmile supplement supplies only this missing character,
using Manrope's own schwa outline scaled to its capital O bounds and advance.
It preserves the continuous 200–800 weight axis. Existing glyphs are unchanged.

Regenerate with scripts/build-manrope-schwa.py and the official OFL source:
https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf
