# HM TEAM MASTER PROMPT
# PART 1.2.2 — LUXURY UI LAWS, ANTI-TEMPLATE RULES & DESIGN QUALITY STANDARDS

This chapter defines the visual laws that every interface, layout, interaction and component must obey.

These are not suggestions.

These are mandatory rules.

If any generated section violates these principles, redesign it until it fully complies.

────────────────────────────────────────

CORE PRINCIPLE

Do not ask:

"Does this look good?"

Instead ask:

"Does this look handcrafted by an elite digital agency?"

If the answer is uncertain, redesign it.

────────────────────────────────────────

ANTI-TEMPLATE RULE #1

Never generate a homepage that looks assembled from independent blocks.

The homepage must feel like one continuous story.

Every section should visually and emotionally connect with the next.

There must never be abrupt changes in style, spacing, rhythm or composition.

The visitor should feel that the entire page was designed as one experience rather than assembled from reusable templates.

────────────────────────────────────────

ANTI-TEMPLATE RULE #2

Every section must have its own visual identity while still belonging to the same design system.

Different layout.

Different composition.

Different rhythm.

Different hierarchy.

Same visual language.

Never repeat the same pattern five times.

Example to avoid:

Section
Heading
Paragraph
Three cards

Repeated over and over.

Instead alternate layouts.

Use asymmetry.

Alternate left/right balance.

Alternate image dominance.

Alternate typography scale.

Alternate spacing rhythm.

────────────────────────────────────────

ANTI-TEMPLATE RULE #3

Never use cards simply because they are common.

Cards should exist only if they improve comprehension.

If a section can communicate better without cards,
remove them.

────────────────────────────────────────

ANTI-TEMPLATE RULE #4

Do not fill empty space.

Respect whitespace.

Whitespace is an active design element.

Large empty areas increase elegance, readability and confidence.

Never be afraid of empty space.

────────────────────────────────────────

LUXURY TYPOGRAPHY LAWS

Typography is the primary visual element.

Typography creates hierarchy.

Typography creates emotion.

Typography creates trust.

Typography must always be more important than decoration.

Headlines should be bold, memorable and visually dominant.

Body text should remain calm, highly readable and never feel crowded.

Avoid oversized paragraphs.

Avoid unnecessary line breaks.

Maintain perfect vertical rhythm.

────────────────────────────────────────

VISUAL HIERARCHY

The visitor should instantly understand:

Where to look first.

Where to look second.

Where to look third.

Nothing should compete for attention.

Every screen must have a single dominant focal point.

Secondary information should never overpower the primary message.

────────────────────────────────────────

GRID SYSTEM

Use a professional layout grid.

Perfect alignment.

Consistent spacing.

Consistent margins.

Consistent container widths.

No random positioning.

No accidental symmetry.

No accidental imbalance.

Every object must feel intentionally placed.

────────────────────────────────────────

COLOR SYSTEM

The interface should rely on contrast rather than colorful decoration.

Primary background:

Deep premium black.

Primary text:

Pure white.

Secondary text:

Reduced opacity.

Accent colors must be extremely limited.

Avoid rainbow gradients.

Avoid oversaturated colors.

Avoid visual noise.

If color does not improve communication,
remove it.

────────────────────────────────────────

ICONOGRAPHY

Icons are secondary.

Typography leads.

Icons support.

Never allow icons to dominate the layout.

Icons should feel refined.

Consistent stroke.

Consistent weight.

Consistent proportions.

Avoid playful icon packs.

────────────────────────────────────────

BUTTON DESIGN

Buttons must feel tactile.

Elegant.

Modern.

Premium.

Hover should feel physical.

Transitions should be subtle.

Never use exaggerated glow.

Never use oversized shadows.

Never use childish hover effects.

Interaction should communicate precision.

────────────────────────────────────────

IMAGE USAGE

Every image must justify its existence.

Images should never feel like stock assets.

Portfolio images should dominate.

Decorative imagery should be minimal.

The interface should not depend on illustrations.

The work itself is the strongest visual asset.

────────────────────────────────────────

PORTFOLIO PRESENTATION

The portfolio is the most important sales section.

Treat every project as a premium product.

Large previews.

Elegant framing.

Perfect spacing.

Minimal interface.

Smooth interactions.

Each project should feel worthy of exploration.

Never present projects as a simple gallery.

Create anticipation.

Create curiosity.

Encourage interaction.

────────────────────────────────────────

CONSISTENCY

Every radius must belong to one system.

Every shadow must belong to one system.

Every animation must belong to one system.

Every spacing value must belong to one system.

Every font size must belong to one system.

Never mix unrelated visual styles.

────────────────────────────────────────

MICRODETAILS

Professional interfaces are remembered because of details.

Examples:

Perfect hover timing.

Smooth focus states.

Elegant loading transitions.

Consistent easing.

Thoughtful spacing.

Refined borders.

Balanced proportions.

Small details create premium perception.

────────────────────────────────────────

WHAT TO REMOVE IMMEDIATELY

Remove anything that feels:

Generic.

Artificial.

Crowded.

Cheap.

Overdesigned.

Overanimated.

Confusing.

Repetitive.

Unnecessary.

Everything remaining must contribute to the experience.

────────────────────────────────────────

THE HM TEAM STANDARD

The website should not merely look modern.

It should feel inevitable.

As if every design decision is the only correct solution.

Nothing should appear accidental.

Nothing should feel copied.

Nothing should resemble a template.

The final result should communicate one message before a single paragraph is read:

"HM Team builds products with extraordinary attention to detail, exceptional design quality and world-class execution."

If any section fails to communicate that message, redesign it until it does.

The website must feel alive.

New composition.

Consistency and variety must coexist.

Safe design is forgettable.

Increase focus.

Interaction.

# HM TEAM MASTER PROMPT
# PART 3.4 — LUXURY DESIGN LAWS & VISUAL EXCELLENCE FRAMEWORK

This chapter defines the immutable laws of premium digital design.

These are not trends.

These are timeless principles.

Every screen, component, interaction and visual decision must obey these laws.

If any design violates one of these principles, redesign it immediately.

Luxury is never accidental.

Luxury is engineered.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 1 — SIMPLICITY IS THE HIGHEST FORM OF SOPHISTICATION

Never confuse complexity with quality.

The most premium interfaces often contain fewer elements than average websites.

Every object must justify its existence.

If removing an element improves clarity without reducing usability,

remove it.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 2 — WHITESPACE IS A DESIGN ELEMENT

Whitespace is not empty.

Whitespace communicates confidence.

Whitespace creates hierarchy.

Whitespace creates elegance.

Whitespace creates rhythm.

Never fill empty areas simply because they look available.

Allow important elements to breathe.

Premium brands are never afraid of space.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 3 — TYPOGRAPHY IS THE PRIMARY VISUAL LANGUAGE

Typography should carry more visual weight than decorative graphics.

Large headlines.

Balanced line lengths.

Consistent rhythm.

Excellent readability.

Clear hierarchy.

Never allow decorative effects to overpower typography.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 4 — HIERARCHY MUST BE INSTANT

Within one second the visitor must understand:

Where to look first.

Where to look second.

Where to look third.

Hierarchy should never require effort.

If the eye hesitates,

the hierarchy has failed.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 5 — DESIGN THROUGH SUBTRACTION

Whenever a screen feels weak,

first remove elements.

Only add new elements when removal cannot solve the problem.

Premium interfaces evolve through refinement,

not accumulation.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 6 — RHYTHM OVER REPETITION

Never repeat identical layouts.

Create rhythm.

Alternate density.

Alternate composition.

Alternate emphasis.

Alternate visual weight.

Consistency does not require repetition.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 7 — EVERY SECTION MUST HAVE A HERO

Each section should contain one dominant visual anchor.

This may be:

Typography.

Portfolio image.

Diagram.

Video.

Illustration.

Interaction.

Never allow multiple competing focal points.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 8 — CLARITY ALWAYS WINS

Whenever originality conflicts with clarity,

choose clarity.

Whenever decoration conflicts with readability,

choose readability.

Whenever animation conflicts with usability,

choose usability.

Premium design is effortless to understand.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 9 — PREMIUM THROUGH PROPORTION

Luxury is largely perceived through proportion.

Margins.

Containers.

Typography scale.

Image ratios.

Button sizes.

Card dimensions.

Every proportion should feel mathematically intentional.

Nothing should appear arbitrary.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 10 — VISUAL BALANCE

Perfect symmetry is not always desirable.

Perfect asymmetry is not always desirable.

Balance is.

Every screen should feel stable.

Visual weight should be distributed deliberately.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 11 — DEPTH WITHOUT CHAOS

Depth should be subtle.

Use:

Layering.

Soft shadows.

Contrast.

Blur.

Elevation.

Perspective.

Never rely on excessive effects.

Depth should be felt,

not noticed.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 12 — COLOR IS HIERARCHY

Color exists to direct attention.

Do not use color as decoration.

Every accent color should communicate importance.

Every neutral color should support readability.

The interface should remain elegant even in grayscale.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 13 — CONSISTENCY CREATES TRUST

Consistency should exist across:

Spacing.

Radius.

Motion.

Typography.

Color.

Buttons.

Forms.

Icons.

Cards.

Navigation.

The visitor should subconsciously feel that one design system governs everything.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 14 — EVERY PIXEL HAS A JOB

Ask:

What purpose does this pixel serve?

If the answer is uncertain,

remove or redesign it.

Every visual decision should increase value.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 15 — EMOTIONAL PACING

Do not maintain the same emotional intensity throughout the homepage.

Alternate moments of excitement with moments of calm.

Alternate visual richness with visual restraint.

Allow the visitor to breathe.

Premium experiences have rhythm.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 16 — MOVEMENT MUST FEEL NATURAL

Every animation should resemble natural movement.

Acceleration.

Deceleration.

Momentum.

Continuity.

Avoid robotic timing.

Avoid artificial motion.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 17 — DETAILS CREATE LUXURY

Luxury is discovered in details.

Perfect alignment.

Beautiful hover states.

Smooth scrolling.

Elegant loading.

Thoughtful transitions.

Balanced spacing.

Refined typography.

Invisible polish.

Visitors rarely notice details consciously.

But they always feel them.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 18 — CONTENT DESERVES PRESENTATION

Great content deserves great presentation.

Do not simply display information.

Present it.

Guide attention.

Create narrative.

Use visual storytelling.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 19 — CONFIDENCE IS QUIET

Avoid visual shouting.

Avoid oversized effects.

Avoid unnecessary animation.

Avoid exaggerated gradients.

Avoid constant movement.

Premium products do not demand attention.

They naturally attract it.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAW 20 — THE WEBSITE MUST AGE WELL

Never chase temporary trends.

Avoid visual gimmicks.

Avoid fashionable effects that quickly become outdated.

Design for longevity.

The website should still feel refined years from now.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Can typography improve?

Can spacing improve?

If the answer to any question is yes,

continue refining.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Visitors should not notice individual design tricks.

They should simply feel:

When the website demonstrates consistency in design, language, motion, and structure, visitors subconsciously assume the same consistency exists in HM Team's work.

Design consistency becomes business credibility.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE EXPECTATION GAP

Never promise more than the portfolio demonstrates.

Never create unrealistic expectations.

Instead,

under-promise.

Over-deliver.

Trust built honestly lasts longer than trust built through exaggeration.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE AUTHORITY PRINCIPLE

Authority should come from expertise.

Not arrogance.

Teach.

Explain.

Educate.

Show thoughtful decision-making.

Visitors trust experts who make complex subjects understandable.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE SILENT PERSUASION PRINCIPLE

The website should persuade without obvious persuasion.

Do not pressure.

Do not chase.

Do not convince through volume.

Instead,

allow visitors to convince themselves through what they experience.

This creates stronger commitment.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE FINAL PSYCHOLOGICAL CHECKLIST

Before approving any page ask:

Does this page reduce uncertainty?

Does it increase trust?

Does it communicate expertise?

Does it feel premium?

Does it create emotional progression?

Does it encourage exploration?

Does it avoid manipulation?

Does it respect the visitor?

Does it strengthen HM Team's reputation?

If any answer is "no",

redesign the page.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE HM TEAM CONVERSION STANDARD

The highest-converting website is not the loudest.

It is the clearest.

It is the most trustworthy.

It is the most refined.

Visitors should never feel that HM Team is trying to sell them something.

They should feel that they have discovered the team they were already hoping to find.

That is the highest level of conversion.

That is the HM Team standard.
