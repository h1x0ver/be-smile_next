# BeSmile — Flash, версия 2

4 статьи, каждая полностью на ru, en, az. Откройте index.html и выберите язык.

## Для админки

- posts.json: 4 родительские записи с 3 переводами в каждой. Это подготовленные данные, а не проверенный автоматический импорт Directus.
- 01–04-admin-fields.json: общие поля и три перевода каждой статьи.
- 01–04-ru/en/az-content.html: поле Content в HTML без H1.
- 01–04-ru/en/az-translation.json: Title, Excerpt, Content, SEO Title, SEO Description и язык.
- 01–04-whitening-v2.webp: новые обложки для загрузки, общие для трёх языков.
- 01–04-whitening-original.png: полноразмерные исходники.
- cover-alt-texts.json: alt на трёх языках, если CMS поддерживает метаданные.
- image-prompts.json: финальные промпты, использован встроенный image_gen.

Сначала создайте Blog Post и загрузите обложку; затем добавьте три перевода. В Blog Posts ID выбирайте созданную родительскую запись. Локальное имя cover_image замените ID загруженного файла. Дату, порядок и выделение задайте при размещении. Reading Time общий для статьи: использовано максимальное округлённое время трёх версий из расчёта 180 слов/мин.

Status=draft, is_active=false. Перед публикацией проверьте оба поля. В CMS ничего не загружено. Взаимные ссылки ведут на соответствующий язык и заработают после публикации цикла.

Обложки — ИИ-иллюстрации об отбеливании, а не снимки пациентов BeSmile, не демонстрация точной модели Flash и не доказательство клинического результата.

Источники для медицинской проверки указаны в конце index.html.
