# BeSmile: 4 статьи о Flash

Откройте index.html: полный просмотр текстов, фотографий и полей админки.

- 01–04-content.html — только содержимое поля Content, без H1 (заголовок выводится сайтом).
- 01–04-admin-fields.json — поля по каждому материалу; posts.json — общий пакет для адаптации, не обещание автоматического импорта Directus.
- 01–04-*.webp — обложки для загрузки. 01–04-original.png — исходники.
- image-prompts.json — финальные промпты; использован встроенный image_gen.

Status=draft, is_active=false, даты и sort не заданы. Перед размещением выбрать дату, порядок, флаги и связать перевод с родительским Blog Post. ID медиа после загрузки заменяет локальное имя cover_image. Публикация в CMS не выполнялась. Главную SEO-статью при желании выделить вручную, чтобы не заменить текущий главный материал.

Обложки — синтетические редакционные иллюстрации, не свидетельство результата лечения и не снимки пациентов BeSmile. Alt добавляется в метаданные файла, если поддерживается админкой.

Взаимные ссылки используют предложенные slug: публикуйте весь цикл либо временно удаляйте ссылки на неопубликованные материалы.
